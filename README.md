# Online Distributional Prediction Under Drift and Corruption

This repository contains experimental code associated with:

> **Online Distributional Prediction via Latent Cluster Geometry Under Drift and Corruption**  
> Navyansh Mahla, Prateek Chanda, and Ganesh Ramakrishnan  
> Accepted by Transactions on Machine Learning Research (TMLR), 2026.

## Overview

The paper studies online prediction of a changing data distribution when observations may be corrupted. Rather than tracking only a point estimate, it represents a candidate distribution through a configuration of cluster centers and maps that configuration to a predictive law. A Gibbs quasi-posterior weights configurations using cumulative clustering loss, and posterior averaging gives the predictive distribution. Performance is measured by cumulative Wasserstein-1 prediction error.

The analysis separates the effects of model complexity, bounded causal corruption, and distribution drift. To reduce the effect of stale observations under drift, the paper studies localized-memory approaches, including periodic restart, a sliding window, and exponential discounting.

## Repository contents

- [`wasserstein_regret.py`](./wasserstein_regret.py) implements simulations for quasi-Bayesian clustering, distribution prediction, and Wasserstein-regret comparisons.
- [`regret_plots/`](./regret_plots/) contains example plots generated by the experiments.

The script compares synthetic Gaussian-mixture, Student-t-mixture, and time-varying Gaussian-mixture settings, as well as noise levels and learning-rate schedules. The current entry point runs an adaptive-learning-rate noise experiment for a time-varying Gaussian mixture.

## Requirements

Python 3 and the following packages are needed:

- NumPy
- SciPy
- Matplotlib
- POT (Python Optimal Transport; imported as `ot`)
- tqdm
- scikit-learn

Install them with:

```bash
python -m pip install numpy scipy matplotlib POT tqdm scikit-learn
```

## Run

From the repository root:

```bash
python wasserstein_regret.py
```

The script asks whether to ignore normalization integrals (`y` or `n`), then runs its configured experiment and saves plots under `regret_plots/`. The run is computationally intensive because prediction repeatedly fits Gaussian-process models while searching for cluster centers.

Experiment functions such as `run_experiment`, `run_noise_experiment`, and `run_adaptive_lambda_experiment` are also defined in `wasserstein_regret.py` for use from Python. Their arguments control the number of centers (`p`), observation dimension (`d`), horizon (`T`), distribution type, noise, and learning-rate schedule.
